# Victor Hub AI — Arsenal Pessoal de Produção Real

Plataforma unificada composta por **Landing Page Comercial** de alta conversão e **Victor Hub OS** (painel de comando operacional completo para gestão de projetos, clientes, tarefas, automações e biblioteca de arsenal).

---

## 🚀 Como Rodar Localmente

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Abra no navegador:
```
http://localhost:3000
```

---

## 📁 Estrutura de Rotas

### 1. Área Pública
* `/` — Landing page comercial com apresentação de serviços, prova social, planos sob medida e chamada para ação.

### 2. Victor Hub OS (`/sistema`)
* `/sistema` — **Central de Comando** com métricas em tempo real, foco do dia, projetos ativos e radar comercial.
* `/sistema/projetos` — Gestão e pipeline de entrega dos projetos com tags de tecnologia e progresso percentual.
* `/sistema/clientes` — CRM de clientes e contratos com integração direta para contato no WhatsApp.
* `/sistema/tarefas` — Agenda diária com níveis de urgência e checklist interativo.
* `/sistema/automacoes` — Painel de monitoramento de webhooks e pipelines conectados com trigger manual.
* `/sistema/arsenal` — Biblioteca de prompts de elite, shaders GLSL, templates e agentes de IA com botão de cópia com um clique.
* `/sistema/financeiro` — Visão analítica de MRR, faturamento mensal, histórico de crescimento e contratos faturados.
* `/sistema/configuracoes` — Dados do perfil, chaves de API e preferências do sistema.

* **Estilização:** Tailwind CSS + Glassmorphism & Cyber-Dark Design
* **Ícones:** Lucide React
